## 二、场景分层

### 2.1 分层思路

以线控底盘平台为分析主体，按「从宏观任务到微观操控、再到系统状态」的方向，将系统所处环境划分为 5 个正常场景层；另设风险场景层，承接第六节的安全风险分析。分层与课堂模板中 Environment（道路与交通环境）、Driver（智驾域/远程安全员）、System（本平台）、Vehicle（整车）、Other System（三电/云控/V2X）的要素相对应。

| 层级 | 名称 | 回答的问题 | 本系统对应场景示例 |
|---|---|---|---|
| L1 | 任务场景层 Mission Scenario | 为什么出行、达成什么任务 | 城区 Robotaxi 载客接驳、点对点自动驾驶通勤、园区/物流配送、失效兜底停车 |
| L2 | 环境场景层 Environment Scenario | 在什么样的外部环境中运行 | 道路拓扑与等级、路面条件、气象光照、地理与法规区域 |
| L3 | 交通交互场景层 Traffic Interaction | 与谁发生交互、交互关系如何 | 跟车、切入切出、路口交会、行人/非机动车横穿、静态障碍避让 |
| L4 | 运动操控场景层 Maneuver Scenario | 底盘如何执行车辆运动 | 定速巡航、纵向加减速、转向/变道执行、紧急制动、避障轨迹跟踪、低附着操控、驻车 |
| L5 | 系统状态场景层 System State | 系统处于什么运行/健康状态 | M1 全自动驾驶、降级限速、M2 远程接管、M3 最小风险 MRM、M4 维保 |
| L6 | 风险场景层 Hazard Scenario | 哪些偏离正常的工况构成风险 | 硬件/软件失效、指令超限、极限工况、预期功能局限、网络攻击（见第六节） |

### 2.2 分层之间的关系

- **自上而下约束**：任务层决定环境层与交互层的选择范围；环境与交通交互决定底盘需要完成的操控动作；操控动作在特定系统状态下执行。
- **自下而上支撑**：系统状态保证操控可执行；操控动作响应交通交互；交通行为适配环境条件；最终支撑任务完成。
- **风险层贯穿各层**：任何一层的要素偏离其正常取值范围，都可能进入风险场景，由安全架构（ARCH-06）识别、降级或兜底。

## 三、各场景分层的具体场景要素

### 3.1 L1 任务场景层要素

| 要素类别 | 具体要素 | 取值 / 说明 |
|---|---|---|
| 任务类型 | 载客 / 载货 / 兜底 | 城区载客接驳、物流配送、失效后安全停车 |
| 出行目的 | 通勤、营运、配送 | 点对点出行、网约出租、园区内转运 |
| 路线约束 | 起点—目的地、途经区域 | 结构化道路为主，地理围栏内运行 |
| 运营时段 | 高峰 / 平峰 / 夜间 | 影响车流密度与光照条件 |
| 任务优先级 | 常规运输 / 应急兜底 | 失效兜底场景优先保障安全停车 |

### 3.2 L2 环境场景层要素

| 要素类别 | 具体要素 | 取值 / 说明 |
|---|---|---|
| 道路拓扑 | 道路等级、车道数与标线、车道宽度、弯道半径、交叉口类型 | 城市主干道/支路、城市快速路、高速公路、封闭园区道路、泊车区 |
| 道路纵断面 | 坡度、坡长 | 常规运行 ±12% 以内 |
| 路面条件 | 附着系数 μ、路面破损、轮胎状态 | 干燥沥青 μ≈0.8；湿滑 μ≈0.4~0.6；冰雪 μ≈0.1~0.3（更低附着仅允许蠕行限速） |
| 气象条件 | 晴/阴/雨/雪/雾、能见度、气温 | 能见度 ≥100 m 为常规运行条件；恶劣天气按等级限速 |
| 光照条件 | 白天/夜间、逆光、隧道出入口、照明设施 | 影响感知与定位，间接约束底盘指令范围 |
| 区域法规 | 地理围栏、限速标志、交通规则 | 仅在授权区域与法规允许范围内运行 |
| 基础设施 | V2X 路侧单元、高精地图覆盖、定位基站可用性 | 影响车路云协同与定位可靠性 |

### 3.3 L3 交通参与者交互场景层要素

| 要素类别 | 具体要素 | 取值 / 说明 |
|---|---|---|
| 机动车 | 前车、后车、邻车道车辆 | 相对速度、间距、车型、加减速与转向行为 |
| 弱势交通参与者 | 行人、骑行者、非机动车 | 直行/横穿/停留，出现位置与运动方向 |
| 静态障碍 | 停放车辆、施工围挡、遗洒物、异形障碍 | 位置、尺寸、可通过性 |
| 交通管控 | 信号灯、停车让行标志、交警手势 | 通行权与速度约束 |
| 交互关系 | 跟车、被跟随、汇入汇出、路口交会、避让 | 对应底盘的纵向与横向响应需求 |

### 3.4 L4 车辆运动操控场景层要素

| 要素类别 | 具体要素 | 取值 / 说明 |
|---|---|---|
| 纵向运动 | 车速、目标加速度/减速度、目标车距 | 城区 0~60 km/h，快速/高速 60~120 km/h |
| 横向运动 | 目标转角、横摆角速度、横向加速度、跟踪轨迹 | 车道保持、变道、避让轨迹跟踪 |
| 乘坐品质 | jerk、俯仰/侧倾幅值 | 常规工况纵向 jerk ≤ 2.5 m/s³ |
| 载荷状态 | 整车质量、轴荷分配、偏载程度 | 影响制动距离、转向特性与悬架姿态 |
| 底盘作动量 | 制动压力/夹紧力、驱动/回收扭矩、转向角、悬架刚度与高度作动量 | 由指令经控制分配输出到各执行链路 |

### 3.5 L5 系统运行状态场景层要素

| 要素类别 | 具体要素 | 取值 / 说明 |
|---|---|---|
| 运行模式 | M1 全自动驾驶 / M2 远程接管 / M3 最小风险 MRM / M4 维保 | 与作业3 模式定义一致 |
| 健康状态 | 正常 / 单点降级 / 备份通道运行 / 故障告警 | 由独立监控器诊断给出 |
| 冗余状态 | 主/备控制器、通信链路、电源、执行通道状态 | 关键信号双源采集、双通道比对 |
| 自检状态 | 上电自检、周期自检、故障码清除情况 | 存在未清除的 ASIL 故障时不得进入 M1 |
| 通信状态 | 总线丢包率、指令超时、云控/V2X 链路时延 | 超时按安全策略进入降级或 MRM |

### 3.6 跨层人员状态要素

| 人员类别 | 状态取值 | 说明 |
|---|---|---|
| 远程安全员 | 在岗 / 在线监控中 / 接管操作中 / 离线 | M2 模式下在线且链路时延满足要求方可遥控；M1 下负责监控与应急接管 |
| 乘员 | 在舱就位 / 安全带约束 / 被动安全可用 | L4 车辆无在环驾驶员，不承担驾驶任务 |
| 维保人员 | 安全工位 / 诊断仪接入 / 退出工位 | 仅在 M4 维保模式下介入，车辆限速 5 km/h |

## 四、运行设计条件（ODC）

运行设计条件描述系统**正常运行**所必须满足的设计边界，分为运行设计范围（ODD）、系统状态条件、人员状态条件三组；超出任一条件时，系统应按既有安全策略降级、限速或进入 MRM，而不是继续按正常工况运行。

### 4.1 运行设计范围（ODD）

| 条件项 | 设计范围 | 超出范围时的策略 |
|---|---|---|
| 道路类型 | 结构化城市道路、城市快速路、高速公路、封闭园区道路、泊车区域；不含非铺装越野道路 | 退出 ODD，请求接管或进入 MRM |
| 车速区间 | 城区 0~60 km/h；快速/高速 60~120 km/h | 按道路类型限速 |
| 路面附着 | μ ≥ 0.3；μ 介于 0.1~0.3 时仅允许蠕行限速 | 低附着下降低减速度/转角请求，TCS/ABS 介入 |
| 道路坡度 | ±12% 以内 | 超坡度限制进入降级限速 |
| 气象与能见度 | 能见度 ≥ 100 m；常规雨/雪/雾按等级限速；环境工作温度 -10℃~+40℃（器件耐温 -40℃~+85℃） | 能见度/温度越界退出 ODD |
| 交通密度 | 中低密度车流；行人密集区域限速通行 | 高密度/高风险区域降速 |
| 定位与通信 | 高精定位有效；云控/V2X 链路可容忍短时中断 | 定位丢失或长时通信中断 → MRM |
| 法规区域 | 授权地理围栏内，符合当地自动驾驶准入与限速法规 | 越界即退出运行 |

### 4.2 系统状态条件

| 条件项 | 正常运行要求 |
|---|---|
| 自检与故障 | 上电自检通过；无未清除的 ASIL 相关故障码；故障已隔离且不影响基本运动能力 |
| 通道冗余 | 主/备控制、通信、电源与执行通道状态明确；关键信号双源一致 |
| 模式合法 | 仅在 M1/M2/M3/M4 之间按规则切换；不允许从 M4 直接进入 M1 |
| 指令边界 | 上层指令在车速、转角、减速度、扭矩的物理边界与附着能力之内；超限指令先限幅并反馈不可执行性 |
| 通信供电 | 总线无持续丢包、无指令超时；双路供电正常；传感器数据在有效量程内 |

### 4.3 人员状态条件

| 运行模式 | 人员状态要求 |
|---|---|
| M1 全自动驾驶 | 无在环驾驶员；远程安全员在岗、监控屏在线并可在约定响应时间内接管；乘员就位、被动安全系统可用 |
| M2 远程接管 | 远程安全员在线，遥控链路时延与可靠性满足要求；遥控指令按比例映射为底盘作动量 |
| M3 最小风险 MRM | 无可介入人员；车辆自主完成减速、靠边停车、双闪与上报，人员不承担操控责任 |
| M4 维保 | 维保人员处于安全工位、诊断仪已接入；车辆限速 5 km/h，退出工位后方可恢复行驶模式 |

## 五、典型场景详细论述

### 5.1 场景选取

选取 **「城市主干道巡航跟车，前车紧急制动（邻车道存在社会车辆）」** 作为典型运行场景。该场景同时覆盖 L1 载客接驳任务、L2 城市道路环境、L3 跟车交互、L4 纵向制动与横向保持操控、L5 正常—降级—MRM 的状态衔接，是线控底盘最具代表性的安全相关工况。

### 5.2 场景背景

- 道路：城市主干道，单向两车道，干燥沥青路面，白天，能见度良好，限速 50 km/h。
- 车辆：本车为 L4 Robotaxi，沿本车道直行，车速 40 km/h，跟距满足安全时距；邻车道有社会车辆同向行驶。
- 触发事件：前车遇路口红灯或前方障碍紧急减速，相对距离快速缩短；本车无在环驾驶员，由智驾域决策、线控底盘执行。

### 5.3 时序与底盘动作序列

| 时刻 | 事件 | 底盘平台响应 |
|---|---|---|
| T0 巡航 | 车辆沿车道匀速跟车 | M1 状态；驱动扭矩随速调节；主动悬架抑制俯仰；状态周期上报智驾域与云控 |
| T1 事件触发 | 前车减速度增大、间距缩短；智驾域下发增大的目标减速度与车道保持指令 | DCU 接收指令，启动指令合法性与边界校验 |
| T2 校验确认 | 减速度、转角在附着与物理边界内；双源传感器数据一致 | 校验通过后进入控制分配；不一致则隔离主通道并仲裁降级（SAFE-03） |
| T3 纵向响应 | 需要快速减速 | 切断/回收驱动扭矩 → 协调能量回收与摩擦制动（EMB/液压备份）逐级建压；悬架抑制点头；必要时 ABS/TCS 介入防止抱死 |
| T4 横向保持 | 邻车道有社会车辆，不具备安全变道条件 | 转向保持本车道，禁止侵入邻车道；若智驾域确认存在可控避让空间，底盘按避让轨迹跟踪 |
| T5 停车 / MRM | 前车静止，本车停稳；或制动能力不足、风险未解除 | 停稳后 EPB 夹紧；若主通道异常，备份通道投入；风险无法消除时触发 MRM：双闪、靠边停车、上报云控 |

### 5.4 成功判据

- 不发生追尾或侧向刮蹭；
- 减速度跟踪误差 ≤ 0.05 g；常规减速过程纵向 jerk ≤ 2.5 m/s³；
- 横向车道偏离 ≤ 0.2 m；停稳后 EPB 可靠保持；
- 任一链路异常时 200 ms 内进入降级模式，整车仍可安全停车（SAFE-01）；
- 全过程状态、故障与动作记录可追溯，支持诊断与事后复盘。

### 5.5 与既有作业的追溯

- 架构追溯：纵向动作对应 ARCH-02 线控制动、ARCH-03 线控驱动；横向保持对应 ARCH-01 线控转向；姿态抑制对应 ARCH-04 主动悬架；校验、冗余与 MRM 仲裁对应 ARCH-05/ARCH-06。
- 需求追溯：指令校验对应 SyRS-FUNC-01；制动性能对应 SyRS-PERF-02/03；冗余降级对应 SAFE-01/02/03；网络与指令可信对应 SAFE-05。

## 六、安全风险分析与风险场景列表

### 6.1 分析方法

在典型场景及各层要素范围内，先识别危害来源（执行器失效、传感器失效、通信/电源异常、指令超限、极限附着与姿态工况、感知/规划局限、网络攻击），再逐一描述风险场景、触发诱因、可能后果与风险等级，最后给出缓解措施并追溯到对应架构与安全需求。风险等级按「后果严重度 × 可控性 × 暴露频率」综合评定为高 / 中 / 低。

### 6.2 风险场景列表

| 编号 | 风险场景 | 触发诱因 | 可能后果 | 风险等级 | 关联架构 / 需求 | 缓解措施 |
|---|---|---|---|---|---|---|
| RS-01 | 制动主通道建压失效或迟滞 | EMB 卡钳故障、液压阀卡滞、压力传感器漂移 | 制动距离延长，追尾前车 | 高 | ARCH-02/06；SAFE-01、SAFE-02 | 备份制动通道；双源压力监测；200 ms 内降级；冗余建压与 AEB 兜底 |
| RS-02 | 转向执行失效或卡滞 | 转向电机故障、齿条卡滞、转角信号丢失 | 偏离车道、冲出道路 | 高 | ARCH-01；SAFE-02 | 备份转向通道；转角双源监控；限速并触发 MRM |
| RS-03 | 双通道信号不一致 | 传感器漂移、通信错位导致主备数据偏差 | 误判车辆状态、产生非预期动作 | 中 | ARCH-06；SAFE-03 | 独立监控器实时比对；不一致时隔离主通道并仲裁降级 |
| RS-04 | 总线通信中断或丢包 | 网关故障、线束干扰、总线拥塞 | 指令丢失或底盘状态无法上报 | 高 | ARCH-05；SyRS-AVAIL-01 | 冗余总线；指令超时进入安全态；规定最后有效指令保持策略 |
| RS-05 | 单路电源失效 | 一路电源或熔断器故障 | 执行能力下降、部分链路失效 | 中 | ARCH-05/06；SAFE-02 | 双源供电与故障切换；备份回路保证最小运动能力 |
| RS-06 | 上层指令超限 | 智驾域下发超速、过大转角或过大减速度 | 失控、甩尾、乘坐冲击过大 | 中 | ARCH-05；SyRS-FUNC-01 | 指令合法性与物理边界校验；超限限幅并反馈可执行性 |
| RS-07 | 低附着路面紧急制动 | 雨雪冰面附着低，紧急制动或猛打方向 | 车轮抱死、打滑、甩尾 | 高 | ARCH-02/03；SyRS-PERF | 附着估计；ABS/TCS 调节；提前减速与限速策略 |
| RS-08 | 横风/坡道/偏载导致姿态失稳 | 强侧风、大坡度、载荷偏移 | 侧倾/俯仰过大、轨迹偏移 | 中 | ARCH-04；SAFE-04 | 姿态与轴荷监测；悬架作动补偿；超限限速降级 |
| RS-09 | 预期功能局限（SOTIF） | 感知/规划对异形障碍、弱势交通参与者识别不足 | 底盘收到迟滞或不可执行的指令 | 高 | SAFE-04；ISO 21448 | ODD 边界约束；场景库与边界场景验证；必要时降级避让 |
| RS-10 | 网络攻击或伪造指令 | 总线被入侵、控制指令被伪造篡改 | 非预期加减速或转向 | 高 | SAFE-05；SyRS-CYBER-01 | 指令签名校验；内外分区隔离；入侵检测；诊断日志防篡改 |
| RS-11 | 远程接管链路中断 | 云驾舱通信中断超过约定时长 | 遥控指令丢失，接管失效 | 中 | ARCH-06；M2 退出条件 | 超时自动退出 M2，转入 M3 最小风险 MRM |
| RS-12 | 悬架/载荷异常 | 弹簧或作动器故障、轴荷超限 | 车身姿态异常、轮胎抓地恶化 | 中 | ARCH-04 | 高度/姿态监测；限速告警；触发维保诊断流程 |

### 6.3 风险处置原则

- **预防**：通过冗余设计、边界校验、ODD 约束与场景库验证，使风险场景尽量不进入执行环节。
- **检测与降级**：独立监控器发现异常后隔离故障通道，按「限制功能 → 限速蠕行 → MRM 靠边停车」分级处置。
- **兜底**：备份链路保证最小转向与制动能力；MRM 完成停车、双闪与上报；全过程数据可追溯，支撑后续 FMEA/FTA 与场景补充。
